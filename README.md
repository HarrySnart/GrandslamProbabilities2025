# How Likely is a Grandslam in the 2025 Six Nations?
This project shows an analysis using Frequentist and Bayesian methods to estimate the probabilities of a Six Nations Grandslam in 2025. You can find the accompanying article on Medium here: https://medium.com/towards-data-science/how-likely-is-a-six-nations-grandslam-in-2025-91aadb47963e.
